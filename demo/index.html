Fontlex

Compilers that target fonts. Each demo is a plain text box in a compiled font: the colors, the hidden Markdown markup and the liaison ties are drawn by the font's substitution rules, with no script doing the highlighting. Type in any of them.

  • Python

    Syntax highlighting by a lexer that runs in the shaper.

  • JavaScript

    The same compiler, from a JavaScript lexer spec.

  • Markdown

    GitHub Flavored Markdown rendered line by line, markup hidden, monospaced or proportional.

  • English pronunciation

    Stressed vowels, reduced vowels and silent letters of 30,000 words.

  • French pronunciation

    Silent letters, nasal vowels and liaison for 30,000 words.

  • German genders

    Nouns colored by gender: der blue, die red, das green.

  • German syllables

    Each word's syllables in turn blue and red, as German schools teach reading.

Color fonts render in current Chrome, Firefox and Safari. The learner fonts also come as a browser extension for any web page. Source, tests and the fonts: github.com/fMindstormer/fontlex.
