Fontlex

Fonts that run a lexer inside the text shaper. Each demo is a plain text box in a compiled font: the font draws the colors, with no script doing the highlighting.

  • Python: syntax highlighting, as you type.
  • JavaScript: the same, from a JavaScript lexer spec.
  • Markdown: GitHub Flavored Markdown rendered line by line, markup hidden, monospaced or proportional.
  • German genders: nouns colored by gender, der blue, die red, das green.
  • German syllables: each word's syllables in turn blue and red, as German schools teach reading.
  • English pronunciation: stressed vowels, reduced vowels and silent letters of 30,000 words.
  • French pronunciation: silent letters, nasal vowels and liaison for 30,000 words.

Color fonts render in current Chrome, Firefox and Safari. Source: github.com/fMindstormer/fontlex.
